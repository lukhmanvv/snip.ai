# ✂️ snip.ai

**snip.ai** is a fast, free Windows desktop application that lets you capture any part of your screen and instantly analyze it using Google's Gemini AI. Whether you need to extract text, solve a problem, explain a chart, or debug code on your screen, just snip it and get an answer in seconds.

## ✨ Features

* **Flexible Screen Capture:** Snip a custom region, a specific active window, or your entire screen.
* **Instant AI Analysis:** Sends your capture directly to Gemini AI for immediate results.
* **Bring Your Own Key (BYOK):** 100% free to use. Just plug in your own Gemini API key—no subscriptions or hidden fees.
* **Privacy First:** Your API key is stored locally on your machine, and your screen captures go straight from your PC to the AI provider without passing through any middleman servers.

## 📥 Download & Installation

1. Go to the [**Releases**](https://github.com/lukhmanvv/snip.ai/releases) page on the right side of this repository.
2. Under the latest version, download the `snip.ai-Setup.exe` file.
3. Run the installer. 
   *(Note: Because this is an independent freeware app, Windows Defender SmartScreen might show an "Unknown Publisher" popup. Click **More info** -> **Run anyway** to proceed).*
4. Launch **snip.ai**, open the Settings, and paste in your **Gemini API Key** (you can get a free key from [Google AI Studio](https://aistudio.google.com/)).
5. Start snipping!
